# Content Proof Library — Travelliniwithus

## Obiettivo

Trasformare i contenuti social migliori in patrimonio proprietario: schede, guide brevi, articoli e prove utili anche senza aprire Instagram o TikTok.

Questa libreria serve a tre cose:

- dare sostanza editoriale al sito;
- creare proof per media kit e partner;
- costruire cluster SEO coerenti con la nicchia "posti particolari".

## Intake richiesto a R&B

Per ogni reel/post candidato servono:

| Campo                      | Note                                                          |
| -------------------------- | ------------------------------------------------------------- |
| URL Instagram/TikTok       | link pubblico al contenuto                                    |
| Luogo / brand / esperienza | nome ufficiale e localita                                     |
| Data pubblicazione         | utile per contestualizzare metriche                           |
| Natura contenuto           | organico, invito, collaborazione, affiliate, press trip       |
| Metriche                   | view, reach, salvataggi, condivisioni, commenti               |
| Asset autorizzati          | foto/video riutilizzabili sul sito                            |
| Disclosure necessaria      | sponsorizzato, affiliato, invito, non commerciale             |
| Note pratiche              | prezzo, periodo migliore, limiti, prenotazione, accessibilita |

## Template scheda proprietaria

Ogni scheda deve avere:

- titolo: `Nome luogo: perche vale davvero`
- intro breve con giudizio editoriale;
- per chi ha senso;
- quando evitarlo;
- cosa sapere prima;
- costo/fasce prezzo se disponibili;
- link ufficiale;
- disclosure commerciale se presente;
- CTA coerente: articolo, newsletter, risorse, media kit.

## Prime 10 categorie consigliate

- Locali insoliti
- Esperienze scenografiche
- Hotel con carattere
- Parchi e mondi immersivi
- Weekend particolari
- Mete wow fuori Italia
- Travel tools provati
- Borghi e castelli
- Citta d'arte viste con taglio pratico
- Luoghi romantici non banali

## Regola qualita

La scheda deve essere utile anche a chi non ha visto il reel. Se senza reel non resta nessuna informazione pratica, non e pronta per il sito.
