## 2. Executive verdict

**Travelliniwithus è un creator brand italiano IG-maturo (~172K, verificato, AGCOM), con formula Reel chiara (“posti particolari / meraviglia concreta”) e monetizzazione multi-affiliate aggressiva, ma ancora debole come media company owned.**

| Forza                          | Debolezza                                  |
| ------------------------------ | ------------------------------------------ |
| Audience reale e riconoscibile | Dipendenza algoritmo IG                    |
| Formula hook ripetibile        | Feed recente molto commerciale (~84% core) |
| Disclosure sistematica         | Bio → Linktree, non sito                   |
| Proof DMO Emilia Fantastica    | Footprint web extra-IG quasi nullo         |
| Volume archivio (1.272 post)   | Archivi non convertiti in SEO/schede       |
| Coppia come volto              | Sito pubblico fragile vs repo avanzato     |

**Frase-ponte IG ↔ sito (da audit senior, ancora valida):**

> Travelliniwithus trasforma il _«wow, dove si trova?»_ in _«ecco se ti merita davvero»_.  
> La meraviglia è l’amo, il criterio è la parola data.

### 5.2 Formula Reel `[VERIFICATO]`

1. Disclosure se commerciale (`ADV` / `Invito` / `Invited` / `Affiliazione`)
2. Freccia 👇🏻
3. Hook UPPERCASE (domanda o promessa)
4. Reveal luogo
5. Dettaglio concreto (prezzo, date, menu, sconto)
6. CTA salva / manda / domanda
7. Footer link-in-bio (spesso leetspeak `L1nk` / `sc@nti`)

### 5.3 Cosa rende riconoscibile il brand `[VERIFICATO]`

- Coppia come filtro umano, non luxury pose
- Implicito: _non pensavo esistesse_
- Scenografia raggiungibile
- Prezzi e info usabili subito
- Tono diretto, entusiasta, colloquiale
- Domanda che personalizza la scelta
