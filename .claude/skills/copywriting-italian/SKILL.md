# Copywriting Italiano — Travelliniwithus

Produce copy editoriale italiano coerente con [[brand-voice]] + [[design-dna]] + pillar editoriali.

## Quando attivare

- "Scrivi hero copy per /esperienze"
- "Rewrite intro articolo barcellona"
- "CTA del media-kit"
- "Meta description per pagina collaborazioni"
- "Caption Instagram per [topic]"

## Tono obbligatorio (sintesi da [[brand-voice]])

| È          | Non è              |
| ---------- | ------------------ |
| Caldo      | Formale            |
| Diretto    | Distaccato         |
| Competente | Generico           |
| Personale  | Pubblicitario      |
| Specifico  | Entusiasta a vuoto |

## Pronomi

- **1ª persona plurale** (noi, abbiamo, ci siamo trovati) → esperienza diretta
- **2ª persona** (tu, puoi, trovi) → consiglio pratico al lettore
- NO "il/la viaggiatore/trice"
- NO "loro" generico

## Pipeline

1. **Brief in 1 riga**: cosa deve dire e dove va (hero / intro / CTA / meta / caption)
2. **Identifica intent del lettore**: informazione / ispirazione / decisione / azione
3. **Scegli pillar di riferimento** (vedi [[brand-voice]]): Destinazione / Stile / Pratico / Ispirazione / Shop
4. **Genera 3 varianti** (alternativa per scelta):
   - V1: massima specificità
   - V2: massima emozione
   - V3: bilanciata
5. **Verifica anti-cliché** (lista sotto)
6. **Output**: 3 varianti + verdict consigliato + motivo

## Anti-cliché vietati

- "Se stai leggendo questo articolo..."
- "Il viaggio più bello della tua vita"
- "Un'esperienza che ti cambierà"
- "Tutto quello che devi sapere"
- "La nostra guida definitiva"
- "Il segreto per..."
- "Scopri di più" come CTA
- "Clicca qui"
- Superlativi senza motivo: incredibile, fantastico, magico, unico
- Emoji nelle pagine pubbliche del sito (OK su social/newsletter)

## Esempi di tono

### Hero homepage — V1 specifica

> Siamo Rodrigo e Betta. Cerchiamo posti che si raccontano da soli e ve li portiamo qui, con la guida pratica per arrivarci davvero.

### Intro articolo destinazione — V1 specifica

> Lisbona si lascia camminare. Non c'è una mappa giusta: ogni quartiere ha un ritmo diverso e tre giorni bastano appena per intuirlo. Qui ti raccontiamo dove abbiamo dormito, mangiato, e ci siamo persi senza pentirci.

### CTA media-kit — V3 bilanciato

> Scarica il media kit completo

### Meta description articolo Lisbona — 150 char

> Tre giorni a Lisbona tra Alfama e Belém: dove dormire, cosa mangiare, le viste che valgono il salto. La nostra guida pratica, senza filtri.

## Lunghezze tipiche

| Tipo               | Lunghezza                    |
| ------------------ | ---------------------------- |
| Hero h1            | 6-12 parole                  |
| Hero subtitle      | 12-20 parole                 |
| Eyebrow            | 2-4 parole                   |
| CTA button         | 2-5 parole, verbo all'inizio |
| Meta description   | 140-160 caratteri            |
| Intro articolo     | 40-80 parole                 |
| Caption Instagram  | 100-250 parole + hashtag     |
| Newsletter subject | 35-50 caratteri              |
